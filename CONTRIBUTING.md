# Contributing Guidelines

Thank you for your interest in improving the Component Portal! This project is a private utility tool designed to explore and analyze Tailwind CSS styles. 

Contributions are welcome to improve the dashboard's features, layout, performance, and general developer experience.

---

## ⚠️ Important Legal Warning

To ensure this repository remains strictly compliant with copyright guidelines and educational fair use exemptions:
1. **Do NOT upload proprietary component files**: Do not submit pull requests containing copyrighted UI components or templates from commercial libraries. 
2. **Dashboard Code Only**: We only accept contributions that improve the dashboard codebase (React application, index scripts, CSS styling, etc.) located in `src/`, `public/`, `scripts/`, or configuration files.
3. **No Licenses Violations**: Ensure all submitted dependencies or integrations are under developer-friendly permissive licenses (such as MIT, Apache-2.0, or BSD).

---

## 🛠️ How to Contribute

### 1. Code Style & Standards
- Keep code clean, modular, and performant.
- Stylize using Tailwind CSS classes.
- Ensure all interactive dashboard buttons are keyboard accessible and have descriptive tooltip tags.

### 2. Submitting Improvements
1. Fork this repository.
2. Create a feature branch: `git checkout -b feature/gorgeous-tabs`.
3. Test your changes locally to ensure the dev server (`npm run dev`) runs without issues and builds cleanly (`npm run build`).
4. Commit your changes: `git commit -m "feat: add keyboard navigation to tabs"`.
5. Push to your branch and open a Pull Request.

---

## 💬 Getting Help
If you encounter bugs in the indexing scripts or have suggestions for UX enhancements, please open an Issue detailing the error logs and your local environment setup.
